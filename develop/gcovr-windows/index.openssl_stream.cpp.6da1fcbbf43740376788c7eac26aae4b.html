36 /*
37 openssl_stream Architecture
38 ===========================
39
40 TLS layer wrapping an underlying stream (via any_stream). Supports one
41 concurrent read_some and one concurrent write_some (like Asio's ssl::stream).
42
43 Data Flow (using BIO pairs)
44 ---------------------------
45 App -> SSL_write -> int_bio_ -> BIO_read(ext_bio_) -> out_buf_ -> s_->write_some -> Network
46 App <- SSL_read <- int_bio_ <- BIO_write(ext_bio_) <- in_buf_ <- s_->read_some <- Network
47
48 WANT_READ / WANT_WRITE Pattern
49 ------------------------------
50 OpenSSL's SSL_read/SSL_write return SSL_ERROR_WANT_READ or SSL_ERROR_WANT_WRITE
51 when they need I/O. Our coroutine handles this by:
52
53 1. Call SSL_read or SSL_write
54 2. Check for pending output in ext_bio_ via BIO_ctrl_pending
55 3. If output pending: write to network via s_->write_some
56 4. If SSL_ERROR_WANT_READ: read from network into ext_bio_ via s_->read_some + BIO_write
57 5. Loop back to step 1
58
59 Renegotiation causes cross-direction I/O: SSL_read may need to write
60 handshake data, SSL_write may need to read. Each operation handles
61 whatever I/O direction OpenSSL requests.
62 */
